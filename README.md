# VALORANT マップ攻略ガイド

ランク戦を前提にしたVALORANTマップ攻略サイトです。

## 今回の更新
- ホームのモード選択（すべて / デフォルト / コンペティティブ / スイフトプレイ）を削除
- 全マップをランク想定に統一
- マップは実装が古い順に掲載
- 各マップの最初のページを「マップ」に統一
- マップ全体像と名称一覧を最初に表示
- マップの特徴を詳細化
- バインドの指定画像をそのまま掲載
- 提供されたエージェント画像を元画像のまま掲載
- 未提供エージェントはVALORANT公式エージェント一覧に対応する公式素材を表示
- PC / Androidスマートフォン対応
