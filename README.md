# VALO MAP GUIDE

VALORANTのマップ情報を調べるためのレスポンシブな静的サイトです。

## 起動
`index.html` をブラウザで開くだけで動作します。

## 構成
- ホーム：全マップのショートカット
- 左サイドバー：全ページ共通のマップナビゲーション
- マップページ：Overview / Locations / Agents / Tips のタブ
- スマホ：サイドバーをハンバーガーメニュー化
- 検索：マップ名・説明などを簡易検索
- 外部ライブラリ不要

## 今後の拡張候補
1. 公式マップ画像を背景にしたインタラクティブなコールアウト地図
2. エージェントごとの詳細ページ・スキル情報
3. 攻撃/防衛別のおすすめセットアップ
4. パッチごとのエージェント/マップ評価の更新
5. お気に入りマップ機能
